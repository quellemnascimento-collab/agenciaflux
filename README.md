## O que é a FLUX

A FLUX não é mais uma agência de marketing. É um **sistema de marketing** que integra estratégia, design, copy e IA em cada entrega — para que o resultado apareça antes do esforço.

> *"Não é sobre postar mais. É sobre postar com sistema."*

### Os 4 Layers da Metodologia FLUX

| Layer | O que entrega |
|-------|--------------|
| **1. Estrutura Visual** | Design com hierarquia e identidade calibrada para conversão |
| **2. Copy Estratégica** | Texto com lógica de conversão e variáveis de nicho |
| **3. Prompt de IA** | Instrução pronta para personalizar em 30 segundos |
| **4. Instrução de Veiculação** | Rede, horário e formato ideais para cada post |
